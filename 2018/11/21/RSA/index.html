We discuss the problem of sending a message secretly over the internet. Suppose the original message is a sequence xxx, the encrypted message is yyy.

XOR Encryption

One solution is to via the XOR operation. Suppose there is a key kkk that is known both to the sender the receiver. Given an integer n∈Nn \in \mathbb{N}n∈N, denote (n)2(n)_2(n)2​ its binary representation.

Sender Encryption. $ (y)_2 = (x)_2 \oplus (k)_2. $

Receiver Decryption. $ (x)_2 = (y)_2 \oplus (k)_2. $

Analysis

Given xxx with length nnn, if kkk is sampled uniformly at random from {0,1}n\{0, 1\}^n{0,1}n, then (y)2(y)_2(y)2​ is a sequence uniformly at random from {0,1}n\{0, 1\}^n{0,1}n. If the message is sent only one time, the eavesdropper can't get more information about xxx after seeing yyy.

Two drawbacks exists.

  1. How can the sender exchange the key kkk with the receiver without meeting each other?

  2. If the many messages are sent, there are frequency pattern associated with yyy, making it breakable.

RSA Encryption

RSA encryption algorithm overcomes the first issue by generating two keys for the receiver: the secrete key and the public key. The public key is distributed across the internet. The sender encrypts the message xxx with the public key. Only the receiver who has the secret key can decrypt the message. The mathematics behind is explained as follows.

Question to ponder: can we attack RSA by the frequency pattern?

Encryption and Decryption

Release the pair as public key:

(N,e). (N, e). (N,e).

And keep in secrete the triple as private key:

(p,q,d). (p, q, d). (p,q,d).

The algorithm for encryption and decryption is as follows:

Sender Encryption. $ y \equiv x^e \pmod N. $

Receiver Decryption. $ x \equiv y^d \pmod N. $

To prove the correctness of the algorithm, we have

Theorem $ x^{e d} \equiv x \pmod N. $

Proof.
