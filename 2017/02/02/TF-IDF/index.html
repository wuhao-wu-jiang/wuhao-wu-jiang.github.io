TF-IDF

02 February 2017Hao Wu~1 min read

TF-IDF stands for term frequency and inverse document frequency. It evaluates the importance of a word to a document in a corpus, which increases with the number of times it appears in the document but is offset by its frequency in the corpus. More precisely, for TF, we define

tf(term∣document)=the number of times "term" appears in "document"total number of words in "document" tf(term| document) = \frac{\mbox{the number of times "term" appears in "document"} }{\mbox{total number of words in "document"} } tf(term∣document)=total number of words in "document"the number of times "term" appears in "document"​

For IDF, we define

idf(term)=1+log⁡(the total number of documentsthe number of documents this term appears in) idf(term) = 1 + \log(\frac{\mbox{the total number of documents} }{\mbox{the number of documents this term appears in} } ) idf(term)=1+log(the number of documents this term appears inthe total number of documents​)

V(Q)=[tf(t1∣Q)∗idf(t1),tf(t2∣Q)∗idf(t2),...,tf(tn∣Q)∗idf(tn)] V(Q) = [tf(t_1 | Q)* idf(t_1), tf(t_2|Q) * idf(t_2),..., tf(t_n|Q) * idf(t_n)] V(Q)=[tf(t1​∣Q)∗idf(t1​),tf(t2​∣Q)∗idf(t2​),...,tf(tn​∣Q)∗idf(tn​)]
