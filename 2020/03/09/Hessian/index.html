Theorem. A twice continuous differentiable function $f:\mathbb{ R } ^n \mathbb{ R } ightarrow \mathbb{ R } $ is convex if and only if ∇2f(x)⪰0\nabla^2 f(x) \succeq 0∇2f(x)⪰0 for x∈Rnx \in \mathbb{ R } ^nx∈Rn.

f(y)=f(x)+∇f(x)T(y−x)+12(y−x)T∇2f(z)(y−x)≥f(x)+∇f(x)T(y−x) \begin{aligned} f(y) &= f(x) + \nabla f(x)^T (y - x) + \frac{1}{2} (y - x)^T \nabla^2 f(z) (y - x) \\ &\ge f(x) + \nabla f(x)^T (y - x) \end{aligned} f(y)​=f(x)+∇f(x)T(y−x)+21​(y−x)T∇2f(z)(y−x)≥f(x)+∇f(x)T(y−x)​

  1. Only If: Rearranging the Taylor series we get,

    f(y)−f(x)−∇f(x)T(y−x)=12(y−x)T∇2f(z)(y−x) \begin{aligned} f(y) - f(x) - \nabla f(x)^T (y - x) &= \frac{1}{2} (y - x)^T \nabla^2 f(z) (y - x) \end{aligned} f(y)−f(x)−∇f(x)T(y−x)​=21​(y−x)T∇2f(z)(y−x)​

    (y−x)T∇2f(z)(y−x)≥0 \begin{aligned} (y - x)^T \nabla^2 f(z) (y - x) \ge 0 \end{aligned} (y−x)T∇2f(z)(y−x)≥0​
