Pushdown Automata

Pushdown automata resemble nondeterministic finite automata but have access to unlimited memory, modeled as a stack that operates on a first-in, last-out (FILO) principle.

Definition. A pushdown automaton is a six-tuple ⟨Q,Σ,Γ,δ,S,F⟩\langle Q, \Sigma, \Gamma, \delta, S, F \rangle⟨Q,Σ,Γ,δ,S,F⟩, where

  • QQQ is a finite set of states,
  • Σ\SigmaΣ is a finite set of input symbols,
  • Γ\GammaΓ is a finite set of stack symbols,
  • δ:Q×Σϵ×Γϵ→P(Q×Γϵ)\delta : Q \times \Sigma_{\epsilon} \times \Gamma_{\epsilon} \to P(Q \times \Gamma_\epsilon)δ:Q×Σϵ​×Γϵ​→P(Q×Γϵ​) is the transition function, where Σϵ=Σ∪{ϵ}\Sigma_{\epsilon} = \Sigma \cup \{ \epsilon \}Σϵ​=Σ∪{ϵ}, Γϵ=Γ∪{ϵ}\Gamma_\epsilon = \Gamma \cup \{ \epsilon \}Γϵ​=Γ∪{ϵ}, and P(Q×Γϵ)P(Q \times \Gamma_\epsilon)P(Q×Γϵ​) is the power set of Q×ΓϵQ \times \Gamma_\epsilonQ×Γϵ​,
  • S∈QS \in QS∈Q is the start state and
  • F⊆QF \subseteq QF⊆Q is a finite set of accept states.

At the core of a pushdown automaton's definition is its transition function. The next move is determined by three elements from the domain Q×Σϵ×ΓϵQ \times \Sigma_{\epsilon} \times \Gamma_{\epsilon}Q×Σϵ​×Γϵ​:

  • The current state.
  • The next input symbol σ∈Σϵ\sigma \in \Sigma_\epsilonσ∈Σϵ​:
    • If σ=ϵ\sigma=\epsilonσ=ϵ, the machine moves without consuming input.
  • The symbol γ∈Γϵ\gamma \in \Gamma_\epsilonγ∈Γϵ​ at the top of the stack:
    • If γ=ϵ\gamma=\epsilonγ=ϵ, the machine moves without reading or popping the stack.
    • Otherwise, the machine pops γ\gammaγ from the stack.

The machine transitions to a new state and updates the stack based on a pair from the domain Q×ΓϵQ \times \Gamma_\epsilonQ×Γϵ​:

  • It enters a (possibly new) state.
  • It may push a symbol γ∈Γϵ\gamma \in \Gamma_\epsilonγ∈Γϵ​ onto the stack:
    • If γ=ϵ\gamma=\epsilonγ=ϵ, no symbol is written.

What can be computed by Pushdown Automata

Theorem. The class of context-free languages is closed under union, concatenation, and star operations.

What cann't be computed by Pushdown Automata

Pumping Lemma. For every context-free language LLL, there is a number ppp, such that for every ω∈L\omega \in Lω∈L, if the length of ω\omegaω is greater than ppp, then ω\omegaω can be devided into five pieces ω=axyzb\omega = axyzbω=axyzb, satisfying the following three conditions:

Context-Free Grammar

Definition. A context-free grammar is a four-tuple ⟨N,Σ,S,R⟩\langle N, \Sigma, S, R\rangle⟨N,Σ,S,R⟩, where

  • NNN is a finite set of symbols called the variables,
  • Σ\SigmaΣ is a finite set of symbols, disjoint from NNN, called the terminals,
  • S∈NS \in NS∈N is the start symbol, and
  • RRR is a finite set of rules, with each rule of the form X→ωX \to \omegaX→ω, where X∈NX \in NX∈N and ω∈(N∪Σ)+\omega \in (N \cup \Sigma)^+ω∈(N∪Σ)+.

Computation. Let u,v,w∈(N∪Σ)∗u, v, w \in (N \cup \Sigma)^*u,v,w∈(N∪Σ)∗.

  • Say that uAvuAvuAv yields uwvuwvuwv, written uAv⇒uwvuAv \Rightarrow uwvuAv⇒uwv, if there exists a rule A→wA \to wA→w of the grammar,
  • Say that uuu derives vvv, written u⇒∗vu \stackrel{*}{\Rightarrow} vu⇒∗v, if u=vu = vu=v or if a sequence u1,u2,…,uku_1, u_2, \ldots, u_ku1​,u2​,…,uk​ exists for k≥0k \ge 0k≥0 and
u⇒u1⇒u2⇒…⇒uk⇒v. u \Rightarrow u_1 \Rightarrow u_2 \Rightarrow \ldots \Rightarrow u_k \Rightarrow v. u⇒u1​⇒u2​⇒…⇒uk​⇒v.

The language of the grammar is {w∈Σ∗∣S⇒∗w}\{ w \in \Sigma^* | S \stackrel{*}{\Rightarrow} w \}{w∈Σ∗∣S⇒∗w}.

Chomsky Normal Form. A context-free grammar ⟨N,Σ,S,R⟩\langle N, \Sigma, S, R\rangle⟨N,Σ,S,R⟩ is in chomsky normal form if each rule is of one of the two forms

  • X→YZX \to YZX→YZ, where X∈NX \in NX∈N, and Y,Z∈N∖{S}Y, Z \in N \setminus \{ S \}Y,Z∈N∖{S},
  • X→aX \to aX→a, where X∈N,a∈ΣX \in N, a \in \SigmaX∈N,a∈Σ.

In addition, we permit S→ϵS \to \epsilonS→ϵ, where SSS is the start variable.

Equivalence between Context-Free Grammar and Pushdown Automata

  1. For every context-free grammar GGG, there is an automaton MMM, such that MMM recognizes the language generated by GGG.

  2. If a pushdown automaton recognizes some language, then it is context-free.

Proof: For the convenience of proof, we modify a pushdown automaton M=⟨Q,Σ,Γ,δ,S,F⟩M = \langle Q, \Sigma, \Gamma, \delta, S, F \rangleM=⟨Q,Σ,Γ,δ,S,F⟩ to give it three features:

  • MMM accepts by entering empty stack.
  • These is only one accept state qaccpetq_{accpet}qaccpet​ in FFF.
  • Each transition either pushes a symbol onto the stack or pops one off the stack, but it does not do both at the same time.

The way to construct a context-free grammar GGG from the push-down automaton MMM is given by follow:

(1) ∀p∈Q\forall p \in Q∀p∈Q, we put the rule Npp→ϵN_{pp} \to \epsilonNpp​→ϵ in G.
(2) ∀p,q,r∈Q\forall p,q,r \in Q∀p,q,r∈Q, we add to GGG a new rule Npq→NprNrqN_{pq} \to N_{pr} N_{rq}Npq​→Npr​Nrq​,

Ullman give another way of converting a pushdown automaton into context-free grammar. In that way, we can avoid construct meaningless rules even for pushdown automaton M1M1M1. The key idea is, rule like Npq→aNrsbN_{pq} \to a N_{rs}bNpq​→aNrs​b is constructed if and only if in state qqq the stack is the same as what it is before the automaton entering state ppp.
