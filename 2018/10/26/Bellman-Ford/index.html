Bellman Ford

26 October 2018Hao Wu~3 min read

Here we discuss the Bellman Ford algorithm for computing shortest path or negative cycle in an undirected weighted graph G=(V,E,W)G = (V, E, W)G=(V,E,W) that contains negative edges.

Recall the Dijkstra algorithm bases on the induction of the number of vertices. The Bellman Ford algorithm, on the other hand, bases on the induction of the number of edges of the shortest path.

Let Pk=(s,v1,v2,..,vk,t)P_k = (s, v_1, v_2, .., v_k, t)Pk​=(s,v1​,v2​,..,vk​,t) be the shortest path between sss and ttt. If we finds the shortest Pk−1=(s,v1,v2,...,vk−1)P_{k - 1} = (s, v_1, v_2, ..., v_{k - 1})Pk−1​=(s,v1​,v2​,...,vk−1​), then we can easily find the path PkP_kPk​. To this end, we define dist[v] the distance from source node sss to vertex vvv.

std::vector<int> dist(n, INT_MAX); 
std::vector<int> pred(n, 0);
dist[s] = 0;
for(int i = 0; i < n - 1; ++i) {
    for each edge (u, v) {
        if(dist[u] + w(u, v) < dist[v]) {
            dist[v] = dist[u] + w(u, v);
            pred[v] = u;
        }
    }
}

If the graph does not contain a negative cycle, the above code compute the shortest path correctly. On the other hand, to check the existence of a negative, we could execute an additional iteration after the above code

bool check_negative_cycle() {
     for each edge (u, v) {
        if(dist[u] + w(u, v) < dist[v]) {
            dist[v] = dist[u] + w(u, v);
            pred[v] = u;
            return true;
        }
    }    
    return false;
}
