Fingerprints for Testing Multi Set Equality

11 March 2021Hao Wu~3 min read
On this page

Problem

Let v⃗=(v1,...,vd)∈Rd\vec v = (v_1, ..., v_d) \in \mathbb{R}^dv=(v1​,...,vd​)∈Rd be a vector, such that ∃\exists∃ some positive integer MMM, ∀i∈[d],vi∈[M]\forall i \in [d], v_i \in [M]∀i∈[d],vi​∈[M]. Assume that ddd is very large and v⃗\vec vv is sparse, so it is represented by a set of pairs that record the non-zero positions and values of v⃗:\vec v:v:

S(v⃗)≐{(i,vi):vi≠0,∀i∈[d]}. S(\vec v ) \doteq \{ (i, v_i ) : v_i \neq 0, \forall i \in [d] \}. S(v)≐{(i,vi​):vi​=0,∀i∈[d]}.

A fingerprint h(v⃗)∈Rh( \vec v) \in \mathbb{R}h(v)∈R is a succinct summary of v⃗\vec vv, which can be used to test whether two vectors v⃗,u⃗∈Rd\vec{v}, \vec{u} \in \mathbb{R}^dv,u∈Rd are equal.

Goal: For a given δ∈(0,1)\delta \in (0, 1)δ∈(0,1), find an h:Rd→Rh: \mathbb{R}^d \rightarrow \mathbb{R}h:Rd→R, such that, ∀v⃗,u⃗∈Rd\forall \vec v, \vec u \in \mathbb{R}^d∀v,u∈Rd, if v⃗≠u⃗\vec v \neq \vec uv=u, then

Pr⁡[h(v⃗)=h(u⃗)]≤δ. \Pr [ h( \vec v) = h ( \vec u) ] \le \delta. Pr[h(v)=h(u)]≤δ.

Solution

Theorem. Let p≥max⁡{d/δ,M}p \ge \max\{ d / \delta, M \}p≥max{d/δ,M} be a prime number and let aaa be an integer generated from 111 to p−1p - 1p−1 uniformly at random. Then

h(v⃗)≐∑i∈[d]vi⋅ai h( \vec v ) \doteq \sum_{i \in [d] } v_i \cdot a^i h(v)≐i∈[d]∑​vi​⋅ai

satisfies the goal.

Remark. It is easy to see that fingerprint is a linear summary:

h(v⃗)=[a,a2,…,ad][v1,v2,⋮vd]. h(\vec{v}) = \begin{bmatrix} a, a^2, \ldots, a^d \end{bmatrix} \begin{bmatrix} v_1, \\ v_2, \\ \vdots \\ v_d \end{bmatrix}. h(v)=[a,a2,…,ad​]​v1​,v2​,⋮vd​​​.

Proof. ∀v⃗,u⃗∈Rd\forall \vec v, \vec u \in \mathbb{R}^d∀v,u∈Rd, if v⃗≠u⃗\vec v \neq \vec uv=u, if h(v⃗)=h(u⃗)h( \vec v) = h ( \vec u)h(v)=h(u), then

∑i∈[d](vi−ui)⋅ai=0. \sum_{i \in [d] } (v_i - u_i) \cdot a^i = 0. i∈[d]∑​(vi​−ui​)⋅ai=0.

However, the polynomial p(x)≐∑i∈[d](vi−ui)⋅xip(x) \doteq \sum_{i \in [d] } (v_i - u_i) \cdot x^ip(x)≐∑i∈[d]​(vi​−ui​)⋅xi has at most ddd distinct roots. As p(0)=0p(0) = 0p(0)=0, it has at most d−1d - 1d−1 distinct non-zero root. The probability that a≠0a \neq 0a=0 being one of them is bounded by

Pr⁡[a is a root of p(x)]=d−1p−1≤dp=δ. \Pr \left[ a \text{ is a root of } p(x) \right] = \frac{d - 1 }{ p - 1} \le \frac{ d } { p } = \delta. Pr[a is a root of p(x)]=p−1d−1​≤pd​=δ.

□\square□
