Set Cover Problem

Let Ω={a1,…,an}\Omega = \{ a_1, \ldots, a_n \}Ω={a1​,…,an​} be a set, and S1,…,SmS_1, \ldots, S_mS1​,…,Sm​ be subsets of Ω\OmegaΩ, such that SjS_jSj​ is associated with weight wj∈R+w_j \in \mathbb{R}^+wj​∈R+ for each j∈[m]j \in [m]j∈[m]. The goal is solve the following the following optimization problem

min⁡J⊆[m]∑j∈Jwj,s.t.∪j∈JSj=Ω \begin{array}{lll} &\min_{J \subseteq [m]} &\sum_{j \in J} w_j, \\ &\text{s.t.} &\cup_{j \in J} S_j = \Omega \end{array} ​minJ⊆[m]​s.t.​∑j∈J​wj​,∪j∈J​Sj​=Ω​

Rounding the Optimal Primal Solution

For each element i∈[n]i \in [n]i∈[n], let Ei≐{j∈[m]:ai∈Sj}E_i \doteq \{ j \in [m] : a_i \in S_j \}Ei​≐{j∈[m]:ai​∈Sj​}, and let C=max⁡i∈[n]∣Ei∣C = \max_{i \in [n]} |E_i|C=maxi∈[n]​∣Ei​∣.

Theorem.

J≐{j∈[m]:xj∗≥1C} J \doteq \left\{ j \in [m] : x_j^* \ge \frac{1}{C} \right\} J≐{j∈[m]:xj∗​≥C1​}

∑j:ai∈Sjxj≥1. \sum_{j : a_i \in S_j} x_j \ge 1. j:ai​∈Sj​∑​xj​≥1.

∑j∈Jwj≤∑j∈Jwj⋅(xj∗⋅C)≤C⋅∑j∈[m]wj⋅xj∗. \sum_{j \in J} w_j \le \sum_{j \in J} w_j \cdot \big( x_j^* \cdot C \big) \le C \cdot \sum_{j \in [m]} w_j \cdot x_j^*. j∈J∑​wj​≤j∈J∑​wj​⋅(xj∗​⋅C)≤C⋅j∈[m]∑​wj​⋅xj∗​.

Rounding the Optimal Dual Solution

Let yi∗,i∈[n]y_i^*, i \in [n]yi∗​,i∈[n] be the optimal solution to the dual.

Theorem.

J′≐{j∈[m]:∑i:ai∈Sjyi∗=wj} J' \doteq \left\{ j \in [m] : \sum_{i: a_i \in S_j} y^*_i = w_j \right\} J′≐⎩⎨⎧​j∈[m]:i:ai​∈Sj​∑​yi∗​=wj​⎭⎬⎫​

Proof. We prove first that Sj,j∈J′S_j, j \in J'Sj​,j∈J′ is a set cover, then we prove that it is a CCC approximate one.

But this implies that we can increase the value of yk∗y_k^*yk∗​, and therefore increase the value of ∑i∈[n]yi∗\sum_{i \in [n]} y_i^*∑i∈[n]​yi∗​, without violating the dual constraints, contradicting the yi∗,i∈[n]y_i^*, i \in [n]yi∗​,i∈[n] being optimal.

∑j∈J′wj=∑j∈J′(∑i:ai∈Sjyi∗)≤∑i∈[n](∑i:ai∈Sjyi∗)≤C⋅∑i∈[n]yi∗, \sum_{j \in J'} w_j = \sum_{j \in J'} \left( \sum_{i: a_i \in S_j} y^*_i \right) \le \sum_{i \in [n]} \left( \sum_{i: a_i \in S_j} y^*_i \right) \le C \cdot \sum_{i \in [n]} y^*_i, j∈J′∑​wj​=j∈J′∑​​i:ai​∈Sj​∑​yi∗​​≤i∈[n]∑​​i:ai​∈Sj​∑​yi∗​​≤C⋅i∈[n]∑​yi∗​,

The Primal-Dual Method

Rounding the optimal dual solution requires to solve the dual LP optimally, which could be slow even though the LP can be solved in polynomial time. The following algorithm overcomes this drawback by constructing only a feasible dual solution.

  1. yi←0y_i \leftarrow 0yi​←0, for each i∈[n]i \in [n]i∈[n]
  2. J←∅J \leftarrow \emptysetJ←∅
  3. while ∃ak∉∪j∈JSj\exists a_k \notin \cup_{j \in J} S_j∃ak​∈/∪j∈J​Sj​ do
  4. \qquad increase yky_kyk​ until some constraint becomes tight,
  5. \qquad i.e., ∃Sℓ\exists S_\ell∃Sℓ​ with ak∈Sja_k \in S_jak​∈Sj​, s.t., ∑i:ai∈Sℓyi=wℓ\sum_{i: a_i \in S_\ell} y_i = w_\ell∑i:ai​∈Sℓ​​yi​=wℓ​

Proof. We prove first that Sj,j∈JS_j, j \in JSj​,j∈J is a set cover, then we prove that it is a CCC approximate one.

Approximation Ratio. The cost of the approximate solution is given by

∑j∈Jwj=∑j∈J(∑i:ai∈Sjyi)≤∑i∈[n](∑i:ai∈Sjyi)≤C⋅∑j∈[m]yi, \sum_{j \in J} w_j = \sum_{j \in J} \left( \sum_{i: a_i \in S_j} y_i \right) \le \sum_{i \in [n]} \left( \sum_{i: a_i \in S_j} y_i \right) \le C \cdot \sum_{j \in [m]} y_i, j∈J∑​wj​=j∈J∑​​i:ai​∈Sj​∑​yi​​≤i∈[n]∑​​i:ai​∈Sj​∑​yi​​≤C⋅j∈[m]∑​yi​,

Randomized Rounding

We present a randomized algorithm based on the optimal solution xj∗x_j^*xj∗​ for the primal LP.
