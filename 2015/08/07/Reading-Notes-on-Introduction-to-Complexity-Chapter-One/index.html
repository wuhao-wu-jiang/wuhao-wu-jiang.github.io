Finite State Automata (DFA)

We aim to develop a mathematical model of computers based on the following observations:

  1. A computer has internal states.
  2. It processes inputs from a finite alphabet.
  3. Its state transitions are determined by the current state and input.

When the number of internal states is finite, the computer can be modeled as a finite-state automaton.

Definition. A finite state automaton is a five-tuple ⟨Q,Σ,δ,S,F⟩\langle Q, \Sigma , \delta, S, F \rangle⟨Q,Σ,δ,S,F⟩, where

  • QQQ is a finite set called the states,
  • Σ\SigmaΣ is a finite set called the alphabet,
  • δ:Q×Σ→Q\delta : Q \times \Sigma \to Qδ:Q×Σ→Q is a transition function,
  • S∈QS \in QS∈Q is the start state,
  • F⊆QF \subseteq QF⊆Q is the set of accpet states.

Under these definitions, a finite state automaton is a computer designed for a specific task. The "algorithm" for performing this task is hard-wired into the computer, encoded in its internal states and transition function.

What can be computed by the model?

A fundamental question is: what can this mathematical model compute? We use set operations to explore the computational capabilities of this model.

Language. If AAA is the set of all strings that machine MMM accepts, we say that AAA is the language of machine MMM and write L(M)=AL(M) = AL(M)=A. We say that MMM recognizes AAA or that MMM accepts AAA.

Regular Language. A regular language is the language that can be recognized by some finite state automaton.

Set Operations. Let AAA and BBB be languages. We define the regular operations union, concatenation, and star as follows:

  • Union: A∪B={x∣x∈A or x∈B}A \cup B = \{ x \mid x \in A \text{ or } x \in B \}A∪B={x∣x∈A or x∈B}.
  • Concatenation: A∘B={xy∣x∈A and y∈B}A \circ B = \{ x y \mid x \in A \text{ and } y \in B \}A∘B={xy∣x∈A and y∈B}.
  • Star: A∗={x1x2…xk∣k≥0 and each xi∈A}A^∗ = \{ x_1 x_2 \ldots x_k \mid k \ge 0 \text{ and each } x_i \in A \}A∗={x1​x2​…xk​∣k≥0 and each xi​∈A}.

A collection of strings is called a regular language if it can be "computed" or "recognized" by an automaton.

The following theorem states that if two collections of strings are regular languages, then there exist automata that can compute their union, intersection, and concatenation. Moreover, if a collection of strings is a regular language, there exists an automaton that can compute its Kleene star.

Theorem. The class of regular language is closed under union, intersection, concatenation and star operations.

The theorem for union and intersection operations can be easily proven based on DFAs. For concatenation and star operations, the proof is simpler under an equivalent model.

Theorem. Every NFA has an equivalent DFA.

What can't be computed by the model?

To understand the power of finite automata, it is essential to also recognize their limitations. The pumping lemma provides a tool for proving that a language cannot be recognized by any finite automaton.

Theorem (Pumping Lemma). For every regular language LLL, there is a number ppp where, for every ω∈L\omega \in Lω∈L of length at least ppp, ω\omegaω can be devided into three pieces ω=xyz\omega = xyzω=xyz, such that

Regular Expression

Regular expression is a popular application of NFA.

Definition. Say that RRR is a regular expression of an alphabet Σ\SigmaΣ if RRR is

  1. {a}\{ a \}{a} for some a∈Σa \in \Sigmaa∈Σ,

When we want to distinguish between a regular expression RRR and the language that it describes, we write L(R)L(R)L(R) to be the language of RRR.

Theorem. Every regular language has a regular expression that describes it.

Hint: Proving that a DFA can be converted into a regular expression is via a model called generalized nondeterministic finite automaton, GNFA, which is simply nondeterministic finite automaton wherein the transition arrows may have any regular expressions as labels, instead of only members of the alphabet or ϵ\epsilonϵ. We focus on a special form, where there is one arrow goes from every state to every other state and also from each state to itself, except that

  • The start state has no arrows coming in from any other state.

  • There is only a single accept state which is not the same as the start state, and it has no arrows going to any other state.

The formal definitions are given below.

Definition. A generalized nondeterministic finite state automaton is a five-tuple ⟨Q,Σ,δ,S,F⟩\langle Q, \Sigma , \delta, S, F \rangle⟨Q,Σ,δ,S,F⟩, where

  • QQQ is a finite set called the states,
  • Σ\SigmaΣ is a finite set called the alphabet,
  • S∈QS \in QS∈Q is the start state,
  • A∈QA \in QA∈Q is the set of accpet states,
  • δ:(Q−F)×(Q−A)→R\delta : (Q - F) \times (Q - A) \to \mathcal{R}δ:(Q−F)×(Q−A)→R is a transition function, where R\mathcal{R}R is the collection of all regular expressions over Σ\SigmaΣ.

Computation. Let M=⟨Q,Σ,δ,S,F⟩M = \langle Q, \Sigma , \delta, S, F \rangleM=⟨Q,Σ,δ,S,F⟩ be a GNFA and let w=w1w2…wmw = w_1 w_2 \ldots w_mw=w1​w2​…wm​ be a string where each wi∈Σϵw_i \in \Sigma_\epsilonwi​∈Σϵ​.   1. r0=Sr_0 = Sr0​=S,
  2. each si∈L(Ri)s_i \in L(R_i)si​∈L(Ri​), where Ri=δ(ri,ri+1)R_i = \delta(r_i, r_{i + 1})Ri​=δ(ri​,ri+1​) is the regular expression on the arrow from rir_iri​ to ri+1r_{i + 1}ri+1​,
  3. rn=Ar_n = Arn​=A.

Every DFA can be transformed into a GNFA. Then, we iteratively remove states from the GNFA, updating the regular expressions on the arrows at each step while preserving the accepted language. This process continues until only two states remain, and the regular expression on the final arrow represents the desired result.
