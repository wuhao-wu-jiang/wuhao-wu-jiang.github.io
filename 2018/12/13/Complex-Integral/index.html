Riemann Sums

We first review the classical Riemann integral and see how this motivates complex integral. Given an interval [a,b][a, b][a,b], the Riemann integral involves dividing an interval, denoted by [a,b][a, b][a,b], into several smaller sub-intervals.

Definition. A finite sequence P={x0,x1,…,xn}P = \{x_0, x_1, \ldots, x_n \}P={x0​,x1​,…,xn​} is a partition of [a,b][a, b][a,b], if

a=x0<x1<…<xn=b. a = x_0 < x_1 < \ldots < x_n = b. a=x0​<x1​<…<xn​=b.

The length of PPP, denoted as ∥P∥\Vert P \Vert∥P∥, is given by

∥P∥≐max⁡i∈[n]Δi \Vert P \Vert \doteq \max_{i \in [n] } \Delta_i ∥P∥≐i∈[n]max​Δi​

where Δi≐xi−xi−1\Delta_i \doteq x_i - x_{i - 1}Δi​≐xi​−xi−1​ for each i∈[n]i \in [n]i∈[n].

Given a function f:[a,b]→Rf : [a, b] \rightarrow \Rf:[a,b]→R, the Riemann integral computes the sum of the products of the length of each sub-interval and the value of fff at an arbitrary chosen point on that sub-interval. Such a sum is well-defined if it converges when the chosen partition is "refined" enough.

∫abf(x)dx=lim⁡∥P∥→0∑k=1nf(ck)Δk. \int_a^b f(x) dx = \lim_{\Vert P \Vert \rightarrow 0} \sum_{k = 1}^n f(c_k) \Delta_{k}. ∫ab​f(x)dx=∥P∥→0lim​k=1∑n​f(ck​)Δk​.

Complex Integral

Complex integration is performed over curves, specifically over a set of curves that have favorable properties.

Smooth Curve

A point set γ\gammaγ in the C\mathbb{C}C is a ``smooth curve'', if it is either a smooth arc or a smooth closed curve, defined as thus.

Definition. A point set γ\gammaγ in C\mathbb{C}C is said to be a smooth arc if it is the range of some continuous complex-valued function z=z(t),t∈[a,b]z = z(t), t \in [a, b]z=z(t),t∈[a,b], s.t.,

  1. z(t)z(t)z(t) has a continuous derivative on [a,b][a, b][a,b],
  2. z(t)≠0,∀t∈[a,b]z(t) \neq 0, \forall t \in [a, b]z(t)=0,∀t∈[a,b],
  3. z(t)z(t)z(t) is one-to-one on [a,b][a, b][a,b].

A point set γ\gammaγ is called a smooth closed curve if it is the range of some continuous function z=z(t),t∈[a,b]z = z(t), t \in [a, b]z=z(t),t∈[a,b], satisfying conditions (1) and (2) and the following:

  • z(t)z(t)z(t) is one-to-one on the half-open interval [a,b)[a, b)[a,b), but z(b)=z(a)z(b) = z(a)z(b)=z(a) and z′(b)=z′(a)z' (b) = z' (a)z′(b)=z′(a).

Remark: in general, we refer to a function z=z(t)z = z(t)z=z(t), where t∈[a,b]t \in [a, b]t∈[a,b], as "admissible" if it satisfies the conditions (1), (2), and (3) / (⋅\cdot⋅).

To explain the definition, let us consider the scenario where a curve γ\gammaγ is being drawn on a piece of paper using a pen. The position of the pen at each time t∈[a,b]t\in [a, b]t∈[a,b] is given by the function z(t)z(t)z(t), which parameterizes the curve.

To ensure that the curve is smooth, we must adhere to certain guidelines:

  1. We must not lift the pen from the paper during the drawing process, which implies that z(γt)z(\gamma_t)z(γt​) must be continuous.

  2. The velocity of the pen point must be well-defined and finite, and it must also vary continuously. Therefore, z′(t)z'(t)z′(t) must exist and be continuous on the interval [a,b][a, b][a,b].

  3. To avoid sharp corners in the curve (which would require a sudden break in the drawing process), we require that z′(t)z'(t)z′(t) is never zero.

  4. We also require that no point on the curve is drawn more than once, except for the initial and terminal points, which may coincide. In other words, z(t)z(t)z(t) must be one-to-one, except for the endpoints aaa and bbb.

In order to demonstrate that a collection of points γ\gammaγ in the complex plane C\mathbb{C}C forms a smooth curve, we must present an admissible parametrization function z(t)z(t)z(t) whose range is γ\gammaγ. There can be infinite number of such parametrizations if γ\gammaγ is smooth.
