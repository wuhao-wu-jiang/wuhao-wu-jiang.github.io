The correctness of the protocol follows directly from the commutativity of the multiplicative group Fp∗\mathbb{F}_p^*Fp∗​:

S=(ga)b mod p=(gb)a mod p. S = (g^a)^b \bmod p = (g^b)^a \bmod p. S=(ga)bmodp=(gb)amodp.

Security Guarantee

The security of the protocol relies on the computational hardness of the following problem:

Diffie-Hellman Problem (DHP). Given (p,g,A,B)(p, g, A, B)(p,g,A,B) observed by a passive adversary, the problem asks whether the adversary can compute S=gabS = g^{ab}S=gab.

It is clear that DHP can be solved if the following problem is solvable:

Discrete Logarithm Problem (DLP) in Zp∗\mathbb{Z}_p^*Zp∗​. Given the finite cyclic group Zp∗\mathbb{Z}_p^*Zp∗​ of order p−1p - 1p−1, a generator ggg, and an element A∈Zp∗A \in \mathbb{Z}_p^*A∈Zp∗​, the problem asks for a∈[p−1]a \in [p - 1]a∈[p−1] such that

ga≡A(modp). g^a \equiv A \pmod{p}. ga≡A(modp).

However, it is not known whether solving DLP is the only way to solve DHP.

Computation

  1. AAA and BBB can be efficiently computed using fast exponentiation.
  2. S−1S^{-1}S−1 can be computed as follows:
    • By Fermat's Little Theorem: Sp−1≡1(modp)S^{p - 1} \equiv 1 \pmod{p}Sp−1≡1(modp).
    • Hence, S−1≡Sp−2(modp)S^{-1} \equiv S^{p - 2} \pmod{p}S−1≡Sp−2(modp), which can also be computed via fast exponentiation.

Generalization

The protocol can be generalized to other cyclic groups beyond Zp∗\mathbb{Z}_p^*Zp∗​, such as elliptic curve groups. In that case, the security relies on the hardness of the following problem:

Generalized Diffie-Hellman Problem (DHP). Given a finite cyclic group GGG of order nnn, a generator g∈Gg \in Gg∈G, and two elements A=gaA = g^aA=ga, B=gbB = g^bB=gb, the problem is to compute gabg^{ab}gab.

This problem can be solved if the following is easy:

Generalized Discrete Logarithm Problem (DLP). Given a finite cyclic group GGG with operation ∘\circ∘ and order nnn, a generator g∈Gg \in Gg∈G, and an element A∈GA \in GA∈G, the problem asks for a∈[n]a \in [n]a∈[n] such that

ga=g∘⋯∘g⏟a times=A. g^a = \underbrace{g \circ \cdots \circ g}_{a \,\text{times}} = A. ga=atimesg∘⋯∘g​​=A.

It is worth noting that the discrete logarithm problem is not hard in all cyclic groups; hardness depends on the choice of group.
