Although no polynomial-time classical algorithm is known for computing the prime factorization of an integer, primality testing can be done in polynomial time. The central idea behind randomized primality testing is to search for a certificate of compositeness that can be verified efficiently.

In this note, we first review several number-theoretic primitives. Then we discuss Fermat's Test and explain why it fails on Carmichael numbers. Finally, we introduce the Miller--Rabin Test, which strengthens Fermat's Test by searching for nontrivial square roots of unity.

Throughout this note, for a positive integer nnn, we write

[n]={1,2,…,n}. [n] = \{1,2,\ldots,n\}. [n]={1,2,…,n}.

Number Theory Primitives

This section reviews several basic number-theoretic primitives that will be used later, including Bézout's Identity, Fermat's Little Theorem, and Lagrange's Theorem.

Fermat's Test

We begin with Fermat's Test, a simple randomized primality test. The test has one-sided error: if it outputs NO, then nnn is definitely composite; if it outputs YES, then nnn is only probably prime. The test can have false positives, but it works well for many composite numbers.

Algorithm: Fermat's Test

Input: An integer nnn and a repetition parameter TTT.

Output: NO if nnn is composite; YES if nnn is probably prime.

  1. If n≤1n \le 1n≤1, output NO.
  2. If n=2n = 2n=2, output YES.
  3. Repeat the following steps for t=1,2,…,Tt = 1,2,\ldots,Tt=1,2,…,T:

  4. If all TTT iterations pass, output YES.

Miller--Rabin Test

Fermat's Test can fail on Carmichael numbers. The Miller--Rabin Test strengthens Fermat's Test by looking not only at whether

xn−1≡1(modn), x^{n-1} \equiv 1 \pmod n, xn−1≡1(modn),

but also at the intermediate square roots of 111 that appear during the computation.

The key observation is the following.

Nontrivial Square Roots of Unity Modulo a Prime

Lemma. If nnn is prime and

x2≡1(modn), x^2 \equiv 1 \pmod n, x2≡1(modn),

then

x≡1(modn)orx≡−1(modn). x \equiv 1 \pmod n \qquad \text{or} \qquad x \equiv -1 \pmod n. x≡1(modn)orx≡−1(modn).

Here −1(modn)-1 \pmod n−1(modn) denotes the residue n−1n-1n−1.

Proof. From

x2≡1(modn), x^2 \equiv 1 \pmod n, x2≡1(modn),

we have

(x−1)(x+1)≡0(modn). (x-1)(x+1) \equiv 0 \pmod n. (x−1)(x+1)≡0(modn).

Since nnn is prime, it follows that

x−1≡0(modn)orx+1≡0(modn). x-1 \equiv 0 \pmod n \qquad \text{or} \qquad x+1 \equiv 0 \pmod n. x−1≡0(modn)orx+1≡0(modn).

Therefore,

x≡1(modn)orx≡−1(modn). x \equiv 1 \pmod n \qquad \text{or} \qquad x \equiv -1 \pmod n. x≡1(modn)orx≡−1(modn).

n=ab n = a^b n=ab

xn−1≡1(modn) x^{n-1} \equiv 1 \pmod n xn−1≡1(modn)
